The main function will ask the user to decide if they want to update the study room's occupancy or its maximum capacity.
If the user does not choose one of the two options, the program will tell them "Invalid option" and ask them again.
The program will then move to a function based on the user's decision and ask the user if they want if they want to add or subtract.
From there, the program will ask for a number to alter the variable by, then alter to variable by that number and operation.
If the current occupancy is equal to the max occupancy, an led on a raspberry pi will light up to indicate that the room is full.
The program will, finally, update a log file with the current occupancy count.
